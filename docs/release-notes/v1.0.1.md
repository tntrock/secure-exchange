## 中文

### 修正

- 雙因素驗證設定畫面（帳號設定、首次登入強制設定、員工與廠商邀請啟用）除了 QR code，也顯示文字金鑰（每 4 個字元一組）。無法掃描 QR code 時，可在驗證器 App 中手動輸入。
- 文件中的部署檔下載網址改為「最新的 Release」，`git checkout` 改為切到最新的版本標籤。

### 映像

- `ghcr.io/tntrock/secure-exchange:1.0.1`（另有 `1.0`、`latest`）
- `ghcr.io/tntrock/secure-exchange-worker:1.0.1`（另有 `1.0`、`latest`）

### 升級

依[管理員手冊「升級」](https://github.com/tntrock/secure-exchange/blob/v1.0.1/docs/admin-manual.md#15-升級)：換用本版的 `docker-compose.yml`（或把兩個映像標籤改成 `1.0.1`），再 `docker compose pull && docker compose up -d`。沒有新的設定變數，也沒有資料庫遷移。驗證附件：`sha256sum -c *.sha256`

## English

### Fixes

- Two-factor setup screens (account settings, forced enrolment at sign-in, staff and vendor invitations) now show the secret key as text (in groups of four) next to the QR code, so users who can't scan can type it into their authenticator app.
- Docs download deployment files from the latest Release, and `git checkout` switches to the latest release tag.

### Images

- `ghcr.io/tntrock/secure-exchange:1.0.1` (also `1.0`, `latest`)
- `ghcr.io/tntrock/secure-exchange-worker:1.0.1` (also `1.0`, `latest`)

### Upgrading

See the [admin manual, "Upgrading"](https://github.com/tntrock/secure-exchange/blob/v1.0.1/docs/admin-manual.en.md#15-upgrading): use this release's `docker-compose.yml` (or change both image tags to `1.0.1`), then `docker compose pull && docker compose up -d`. No new settings and no database migrations. Verify the attachments: `sha256sum -c *.sha256`
