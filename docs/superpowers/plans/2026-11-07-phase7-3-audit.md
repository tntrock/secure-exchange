# Phase 7.3 — Audit UI, syslog forwarding, notification prefs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admins can browse, filter, export (CSV) and verify the audit log, and every audit row is forwarded to a syslog SIEM without loss. Staff see the audit history of their own shares and can switch off three kinds of notification mail.

**Architecture:**
- `internal/audit` gains richer filters, keyset paging, a streaming iterator and a counting `Verify`.
- A new `internal/syslogfwd` package sends rows after a DB cursor (`syslog_cursor.last_id`) as RFC 5424 messages. It runs inside `serve`, and an advisory lock picks one instance to send.
- Notification prefs are three `users` columns. They are checked where the mail is enqueued (`share/access.go`, `scan/worker.go`).
- Web adds an admin Audit page, a share-history section on ShareDetail, a `/settings` page, and an admin forwarding alert in `Shell`.

**Tech Stack:** Go 1.26, pgx/v5, goose, stdlib `encoding/csv`, `crypto/tls`, `net`; React 19 + TS, vitest, react-i18next.

**Spec:** `docs/superpowers/specs/2026-11-07-phase7-admin-design.md` (§5 audit bullets and staff audit, §6, §7, §8 item 3, §9 audit-order bullet). The parent spec is `docs/superpowers/specs/2026-10-24-secure-exchange-design.md` (§5.8, §5.9).

## Global Constraints

- One PR, branch `phase7-3-audit`. Commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Spec §8: update `docs/admin-manual.md`, `docs/user-manual.md` and `.env.example` in this PR.
- i18n: every new key must exist in both `web/src/i18n/en.json` and `zh-TW.json`; `keys.test.ts` enforces parity.
- Lint uses goimports with `-local github.com/tntrock/secure-exchange`. Third-party and module imports go in separate groups.
- Coverage gate: total Go ≥ 90% (CI `scripts/covergate.sh`); web thresholds in vitest config.
- **Never call a pool-based helper while holding a tx** (pool starvation under `-race`). Inside a tx, query through the tx.
- syslog (spec §6):
  - Format: RFC 5424; MSG is the audit row's JSON including its hash.
  - Transports: UDP, TCP, TLS (with an optional CA). TCP and TLS use octet-counting framing.
  - Forwarding is off when unset.
  - The cursor lives in the DB. Retry until the server is reachable again, then resume from the cursor.
  - Show an admin alert when failures persist.
- Audit ids are commit order (`Append` holds `pg_advisory_xact_lock(7461)`), so the cursor may rely on `id`. With several instances, an advisory lock decides which one forwards (spec §9).
- Hash-chain verification streams rows; it never loads the whole table (spec §9).
- Notification prefs (spec §7): staff may turn off first open, download, and external upload complete. Virus-found mail can never be turned off.

## Rulings made while planning (my calls)

- syslog facility 13 (log audit). Severity 6 (info) when `result == "ok"`, otherwise 4 (warning). APP-NAME `secure-exchange`, PROCID `-`, MSGID = action, STRUCTURED-DATA `-`, no BOM.
- `SX_SYSLOG_TRANSPORT` defaults to `tls`.
- First enable on an existing install sends the whole history from id 1. Delivery is at-least-once: a crash between send and cursor commit can resend at most one batch (500 rows). The manual says so.
- Alert threshold: `failing_since` older than **15 minutes**.
- CSV:
  - Ascending id, UTF-8 BOM (so Excel opens zh-TW correctly).
  - A cell starting with `=`, `+`, `-`, `@`, tab or CR gets a leading `'`.
  - The export ignores paging but keeps every other filter.
- Auditing the audit log: export is audited as `audit.export` with the filter in detail, and verification as `audit.verify`. Plain browsing is not audited.
- Admin audit "target" filter: matches `target_id = X OR detail->>'share_id' = X`, so a share id also finds its file views and downloads.
- The staff share history uses the same query and shows the newest 200 rows. Request detail gets no history; the spec names only the share page.
- The `skipped` (unscanned, over size) upload mail counts as "upload complete", so it can be turned off. `infected` and scan `error` mails always go out.
- Notification prefs apply to `requireUser` accounts (staff/admin). Vendors receive none of these mails.

## Review Focus

1. **CSV formula injection.** A user agent or file name starting with `=` must open in Excel as text: prefixed with `'`. Pinned by Task 3 `TestAuditCSVEscapesFormulas`.
2. **syslog down, then back up.** No row is lost. Rows after the cursor are sent once the listener returns, and a restart resumes from the cursor. Pinned by Task 2 `TestForwarderResumesAfterOutage`.
3. **Two app instances.** Only one forwards; there are no doubled rows in the steady state. Pinned by Task 2 `TestForwarderSingleSender`.
4. **Staff asking for another user's share history.** They get 404, so the share's existence does not leak. A vendor gets 403. Pinned by Task 3 `TestShareAuditOwnerOnly`.
5. **Owner opted out of upload mail.** The infected-file mail still reaches the owner and the admins. Pinned by Task 4 `TestScanInfectedIgnoresOptOut`.

- [ ] **Step 3: Implement**
  - Each `Step`:
    1. Begin a tx and run `SELECT pg_try_advisory_xact_lock(7462)`. If false, commit and return `(0, nil)`.
    2. Read `last_id` with `SELECT … FOR UPDATE`.
    3. Fetch rows with `audit.After(ctx, tx, last, Batch)`.
    4. Dial if there is no live conn. Use the TLS config with `RootCAs` from `CAFile` when set (system roots otherwise) and `ServerName` from the host part of `Addr`. Write every frame with a 10 s write deadline.
    5. Update `last_id`, `last_ok_at = now()`, `failing_since = NULL`, `last_error = ''`, then commit.
  - On a send error:
    - Close the conn, roll back, and record `failing_since = COALESCE(failing_since, now())`, `last_error`.
    - Do this in a separate statement on the pool, after the rollback.
  - `Run` loop:
    - When the batch is full, step again immediately.
    - When the batch is short, sleep `Interval`.
    - On an error, sleep `Retry`.
  - JSON fields: `id, at, actor_type, actor_id, ip, user_agent, action, target_type, target_id, result, detail, prev_hash, hash`. `at` is RFC3339Nano UTC; the hashes are hex.
  - Wire it in `serve`: `if cfg.Syslog.Addr != "" { go (&syslogfwd.Forwarder{...}).Run(ctx) }`. `Host` is `os.Hostname()`.
